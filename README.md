🛍️ Dashboard Overview

This project is an interactive Customer Shopping Analysis Dashboard created using Tableau. It analyzes customer shopping data to understand purchasing behavior, customer satisfaction, product categories, loyalty status, and regional sales patterns.

Dashboard Objective

The main objective of this project is to analyze customer shopping behavior and identify useful trends and insights through interactive data visualization.

Dashboard Features

- Interactive visualizations
- Average purchase amount by age
- Total purchase amount by region
- Customer satisfaction analysis by region
- Sales share by product category
- Customer analysis by loyalty status
- Customer count based on promotion usage
- Easy-to-understand visual representation of customer shopping data

Key Insights

- The average purchase amount varies across different age groups.
- The East region records the highest total purchase amount.
- Customer satisfaction remains almost similar across all regions.
- Different product categories contribute differently to overall sales.
- Regular customers form the largest loyalty group.
- Promotion usage provides insights into customer engagement and purchasing behavior.
- The dashboard helps identify important customer and regional shopping patterns.
